# Screenshots & assets

Image assets for the project README live here. The main [`../readme.md`](../readme.md)
already references the filenames below — just drop the matching files in and they
render automatically (no README edits needed).

| Filename | What to capture | Used in |
|---|---|---|
| `dashboard.png` | Live dashboard — annotated preview + console + Start/Stop | Hero image (top of README) |
| `analytics.png` | Analytics page (charts / class distribution) | Screenshots grid |
| `models.png` | Models page (import / training) | Screenshots grid |
| `login.png` | Login page | Screenshots grid |
| `alerts.png` | Alert rules / notifications | Screenshots grid |

**Tips**
- PNG, ~1280 px wide is plenty; crop to the browser content.
- **Scrub any real names / PII** before committing — use demo accounts.
- Keep each file under ~500 KB so the repo stays light (these are tracked in git).
